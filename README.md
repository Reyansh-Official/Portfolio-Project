# Reyansh Attavar Portfolio

Personal portfolio website built with React and Vite. The site uses an editorial poster-style layout to present education, technical tools, selected projects, and contact links.

## Tech Stack

- React
- Vite
- CSS

## Local Development

```bash
npm install
npm run dev
```

## Production Check

```bash
npm run lint
npm run build
```

## Preview Production Build

```bash
npm run preview
```
